# Скрипты для инеграции с Google Earth

Google Earth (особенно десктопная) 
* имеет шикарный движок рендера
* умеет отображать и поворачивать планы с десятками тысяч объектов без видимых задержек, гличей
* умеет "на лету" визуализировать двумерные объекты в 3Д, если есть для них модельки, например типовые многоэтажки
* умеет отображать меняющуюся позицию нескольких отслеживаемых объектов


Кейсы
* Когда андроидная апа WarDrive начинает тормозить - сгрузить ее экспрот в GE, а из Wardrive удалить
* Когда хочется на большем экране видеть метки и дороги, по которым ты уже проехал или еще не проехал
* Когда нужно загрузить несколько заготовленных гео-файлов для отображения на карте
* Когда хочется отслеживать не только свое положение
* Когда встроенный в телефон GNSS модуль теряет сигнал
  
Подключаем ноду Meshtastic или компаньон Meshcore к GE на ноуте
и используем их GNSS, с хорошей внешней антенной для позиционирования в real-time

Есть два типа такого подключения
1. Через COM-порт на винде или линуксе (на маке невозможо)
2. Через обновляемый kml-файл, в который пишет ваше ПО или скрипт

Вот эта директория содержит скрипты для связывания mesh-устройств с GE

## meshtastic_ble_nmea_bridge.py

запрашивает текущие координаты у мештастика и транслирует их в куда-то в /dev/tty* \
должно работать под windows и linux \
не работает на маке, даже после снятия защиты записи в /dev, GE тупо игнорирует там нефизические устройства \
не проверял пока на других буках

НАСТРОЙКА

для работы нужно на ноде мештастика включить модуль serial bridge и задать его формат в NMEA \
аналог трансляции пакетов GNSS в порт для мешкора пока не видел

## meshtastic_ge_bridge.py

запрашивает текущие координаты у мештастика и формирует kml файл, который опрашивает GE для обновления позиции \
работает крайне нестабильно, так что я забил \
проблемы (возможно виновата слишком новая прошивка, а может мне просто не везет с тастиком, а может...)
* нестабильное и при этом долгое подлючение к ноде
* залипание координат
* отвал GNSS модуля до физического ресета

## meshcore_ge_bridge.py

запрашивает текущие координаты у компаньона meshcore и формирует kml файл, который опрашивает GE для обновления позиции
"на столе" работает идеально
* быстро подключается
* координаты обновляются с каждым запросом
* ничего не падает и модуль GNSS не отваливается, можно сколько угодно раз прерывать и запускать скрипт

# Настройка Google Earth (для обновляемого kml)

* В меню Добавить → Сетевая ссылка  (Add → Network Link)
* Задать адрес http://127.0.0.1:8080/loader.kml
* на вкладке Refresh поставить Periodically с нужным интервалом

# Запуск скрипта

python3 <скрипт>

```bash
python3 meshcore_ge_bridge.py
```
